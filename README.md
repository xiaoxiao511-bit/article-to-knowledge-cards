# make-knowledge-cards

`make-knowledge-cards` 是一个 Codex Skill，用来把文章整理成少量、聚焦且忠于原文的知识卡片。

## 项目解决什么问题

长文章通常包含重复表述、过渡内容和次要细节，直接用来复习不够高效。这个 Skill 会识别文章中真正重要且彼此独立的知识点，把它们转成便于理解和自测的卡片，同时避免加入原文没有的信息。

默认目标是生成 5～8 张卡片。如果原文不足以支持五个独立知识点，它会如实生成更少的卡片，不拆分或重复内容来凑数量。

## 主要功能

- 接受用户直接粘贴的文章。
- 读取用户指定的本地 `.md`、`.markdown` 或 `.txt` 文件。
- 按重要性选择知识点，而不是简单按段落顺序摘要。
- 保证一张卡片只讲一个知识点，并合并语义重复的内容。
- 每张卡片包含标题、核心知识、简明解释，以及原文支持的例子或自测问题。
- 保留原文中的条件、限制和不确定性，不把观点、假设或相关关系改写成确定事实或因果关系。
- 默认使用原文的主要语言输出。

暂不支持网页抓取、PDF、Anki 导出和图形界面。

## 安装方法

将完整的 [`skills/make-knowledge-cards`](skills/make-knowledge-cards) 目录复制到 Codex 的 skills 目录中。安装后应保留下面的结构：

```text
<Codex skills 目录>/
└── make-knowledge-cards/
    ├── SKILL.md
    └── agents/
        └── openai.yaml
```

如果设置了 `CODEX_HOME`，目标目录通常是 `$CODEX_HOME/skills`；未设置时通常是用户主目录下的 `.codex/skills`。复制完成后，重新启动或刷新 Codex，使其发现新 Skill。

## 使用方法

在 Codex 对话中使用 `$make-knowledge-cards`，并粘贴文章内容：

```text
使用 $make-knowledge-cards，把下面这篇文章整理成知识卡片：

<粘贴文章内容>
```

也可以指定一个 Codex 能读取的本地 Markdown 或 TXT 文件：

```text
使用 $make-knowledge-cards，把 notes/learning.md 转换成知识卡片。
```

需要其他输出语言时，可以在请求中明确说明：

```text
使用 $make-knowledge-cards，把 notes/learning.txt 转换成英文知识卡片。
```

## 输入输出示例

输入：

```text
间隔练习是把多次学习分散到不同时间完成，而不是集中突击。复习间隔应随掌握程度逐渐拉长。
```

输出：

```markdown
### 卡片 1：间隔练习的基本做法

**核心知识：** 间隔练习把多次学习分散到不同时间完成，而不是集中突击。

**简明解释：** 多次学习会安排在不同时间，而非集中在一次学习时段中。

**例子或自测问题：** 间隔练习与集中突击在时间安排上有什么区别？

### 卡片 2：逐渐拉长复习间隔

**核心知识：** 随着掌握程度提高，复习间隔应逐渐拉长。

**简明解释：** 对内容掌握得越好，下一次复习可以安排得越晚。

**例子或自测问题：** 当内容掌握得更好时，复习间隔应如何变化？
```

这个输入只包含两个独立知识点，因此输出两张卡片，而不是强行补足五张。
